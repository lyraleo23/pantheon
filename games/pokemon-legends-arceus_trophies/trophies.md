## Notes

Genesis Mode. Nintendo Switch has no native achievement/trophy system, and Legends: Arceus is confirmed the first core-series Pokémon game to release in only one unified version — no other platform, no version-exclusive split. No paid DLC or expansion pass was ever released for this game; the only post-launch content is the free v1.1.0 'Daybreak' update (Feb 2022), which added the Arceus postgame content and is treated as base-game content here since it has been a permanent free part of the game for years — there is no `dlc` block, unlike the last three games covered this session. Scope decisions: (1) PLA-019 (Shaymin) and PLA-020 (Darkrai) both require save data linked from entirely separate Pokémon games (Sword/Shield and Brilliant Diamond/Shining Pearl respectively) — included at explicit user request (who owns both prerequisite games), each marked missable with a note on the external-save dependency for any reader who doesn't. (2) PLA-026 (Pokédex completion) verifies via the Shiny Charm reward rather than citing an exact species count, since no source confirmed the game displays a numeric completion percentage anywhere — the Hisui Pokédex is a physical in-game book whose condition changes visually rather than showing a hard number. (3) A dossier-flagged detail was deliberately NOT turned into its own trophy: certain unique story Alpha Pokémon are reportedly permanently lost if defeated rather than caught, but which specific encounters this applies to beyond a loosely-sourced 'e.g. Alpha Kleavor' example could not be pinned down distinctly from the mandatory Noble Kleavor fight (which uses an unrelated balm-throwing mechanic, not a catch-or-defeat choice) — rather than risk conflating the two and writing a factually wrong trophy, no trophy references this missable Alpha content specifically. (4) Whether Giratina is caught or simply defeated after its battle could not be confirmed, so PLA-024's verification is written to hold true either way.
