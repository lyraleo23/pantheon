## Notes

Genesis Mode — Bayonetta Origins is a Nintendo Switch console exclusive with no PC/PlayStation/Xbox release, so there is no native achievement list to port. No DLC was ever released (a single 1.0.0 build). No content is permanently missable — full backtracking is supported via Fast Travel (unlocked in Chapter 5) and save points. Research surfaced several disputed exact counts that this list deliberately avoids stating: Remembrances (15 across three location-guide sources vs. 12 in a costume-list source) and total costume count (14 vs. 15). Every full-collection trophy for these systems is instead verified through the specific milestone costume the game itself grants for completing that system (e.g., 'Younger Days' for all Remembrances), which sidesteps the disputed numbers entirely — the reward existing at all confirms the game tracks completion internally, regardless of which exact total is correct. The exact total count of individual Vitality Petals was never found by any source, so only an intro-level 'first Vitality Blossom' trophy was built, not a full-collection one. An audit pass also caught a dossier error carried from scouting: the Chapter 3 boss is Fomhorach, the Stalwart Guardian — 'White Wolf' is a guide character who leads Cereza to that fight, not a boss itself; trophies BYOR-006 and BYOR-010 were corrected accordingly. Similarly, 'Forest's Hero' is the name of the final Remembrance unlocked by rescuing every Wisp, not a secret area, and the actual reward costume for that milestone is 'An Elegant Swan' — BYOR-016's verification was corrected to match. Per user confirmation at the dossier checkpoint, the post-game 'Jeanne's Tale' trophy (BYOR-020) deliberately avoids naming its secret final boss or revealing its crossover twist with Bayonetta 3, per Rule 16.
