## Notes

Filter (Rules 10, 20, 21) was waived by the player's choice, so entries such as 'Today Was a Good Day', '...Here we go again', 'Horror of the Santa Maria' and 'Lucky Spinner' are back. Prune found no entry needing content missing on Switch. Sticky Fingers' amount is disputed ($10,000 per gta.wiki/gtabase vs $50,000 per the leak and Steam thread), so its description does not commit to a figure. IDs 001-029 and the Platinum (030) are unchanged from v1.0 so recorded progress survives; restored and new entries take 031-049 in import order (restored console entries first, then Social Club-only). The original v1.0 trophy Breaking the Bank is kept. The count exceeds Rule 4's 40-trophy reference because the mirror is 1:1. Mission-condition trophies stay flagged MISSABLE because mission replay is unconfirmed in the Definitive Edition. '...Here we go again' needs a new game after 100%: save the 100% file in a separate slot first. Cheats are reported to block achievements on other platforms; assume a cheat-free save.
